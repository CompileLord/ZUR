## A. Shared foundation (Phase 1; every later phase builds on this)

| Area | Target |
|---|---|
| Icons | Inline SVG outline set (16/18px, 1.75 stroke, currentColor). No emoji anywhere (the builder currently uses ✏️ 👁 📌 🖼). |
| Page header | One H1 per page. The S3/S6 top bar holds a breadcrumb/context only and never repeats the H1. Top padding 40px, max width ~1040px (tables ~1200px), left aligned. Optional subtitle at most one line, and only where it is actually useful. |
| Sidebar (S3/S6) | Icon + label rows, 36px tall, neutral selected surface + citron leading marker. Help is a normal row. Account block = avatar initials + name + menu (Settings, Sign out). The mode switch follows the route. |
| Buttons | Primary (accent), secondary (outline), ghost, danger, icon. 32px compact in toolbars, 40px elsewhere. One primary per region. |
| Form controls | Themed input/select/textarea/checkbox/radio/date: 40px, 8px radius, control border, custom select chevron. Never a browser-default control. Field = label → control → helper. |
| Sections | Flat sections separated by 32–48px spacing or a single divider. No card-inside-card, and no cards stacked edge to edge. |
| Badges | Small, sentence case, semantic fg/bg, optional icon. A single primitive used for status/verdict/state. |
| Tables | 48px rows, sentence-case headers, muted header text without a heavy filled header band, right-aligned numbers, row hover, trailing ghost/overflow actions, humanized values. |
| Formatters | Dates as `Oct 3, 1:50 PM` or relative; enums humanized (`broken_exercise` → `Broken exercise`, `published` → `Published`); IDs truncated as mono with a copy button; `0m` and other empty metadata hidden. |
| Copy | Cut subtitles that restate the title. Move jargon into a disclosure or tooltip ("immutable", "authoritative records", "Learning-active"). |
| Dialogs | Step-up actions (reason + admin password) live in a confirmation dialog opened by the action button, not as inline forms on the page (applies to Admin/Categories/Media/Execution). |
